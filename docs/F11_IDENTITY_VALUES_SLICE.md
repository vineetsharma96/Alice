# F11 identity and values slice

F11 adds `underworld/identity_values_f11.py` with a bounded, revisable personal
summary, declared initial values, acquired preferences and evidence-backed
commitment proposals. Declared values remain separate from acquired evidence.
Native/public outcomes can change acquired scores, contexts, confidence and
commitments; contrary evidence can revise or remove them.

Summaries and commitment actions are proposal-only, source-linked and JSON
copyable. Self-reported emotion, operator labels, private state, model fields
and circular self-reward are rejected. A commitment proposal must match the
owner/run and be feasible according to the caller's native authority.

This slice does not claim a stable human identity, moral agency, consciousness
or a passed prospective F11 continuity gate.
