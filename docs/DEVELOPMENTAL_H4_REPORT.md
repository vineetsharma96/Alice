# H4: useful world information, bounded native integration

21 October 2026. This is opt-in source research. No application/release label,
native law, G configuration, H0-H3 source registration or existing world changes.
The failed Phase9 study remains sealed and outside live policies.

## Results and scope

| H4 component | Result |
|---|---|
| Useful single location signal | Registered native acquisition gate passes on five new held-out seeds |
| Resource identity versus location | 10/10 separate identity inspections correct; no identity word decodes a location |
| Engineered own-need scheduler | 9 self-selected native consumption goals versus 0 under prediction ablation |
| Source depletion after scouting | 5/5 cases stop without invalid gather or false confirmation |
| Learning/source persistence | Frozen tables, native proofs, save/archive checks and fresh-process continuation pass |
| Autonomous scouting or transmitted information requests | Not implemented; scout circuit and inquiry marker are authored |
| General exploration, long unattended survival, H5 | Deferred; not established by this experiment |

The five confirmation seeds are 9203, 9227, 9257, 9277, 9293. Development uses
43 only. The prospective protocol/source registration is written before these
measurements. No held-out seed is used to tune the implementation. There are
only ten feasible primary cases per arm, so the evidence is narrow.

| Communication arm | Native acquired-and-consumed goals | Rate |
|---|---:|---:|
| Learned location signal | 10/10 | 100% |
| Muted | 5/10 | 50% |
| Scrambled location | 0/10 | 0% |
| Resource identity only | 5/10 | 50% |

Useful signals outperform scrambled signals on all five seeds. The two-site
scenario is balanced; a private tie break without location information chooses
one remembered site, succeeding on one of the two matched counterfactual cases.
No hidden target ID or scout coordinates enter the recipient's policy. Raw
Wilson intervals are descriptive and trials share trained/counterfactual ancestry;
they do not support an independent population inference. The raw zero-success
interval contains a tiny negative floating-point roundoff (about -2.8e-17),
which is zero to reporting precision; raw evidence is preserved unchanged.

## What is learned and what is authored

The recipient learns resource-class associations from actual native physical
H2 demonstrations, separately from location-token associations acquired on real
co-visits. A speaker coins private symbols with its own saved random state;
resource and location productions are disjoint. The recipient remembers its own
visited coordinates. Two finite spatial cells, the 8m spatial abstraction,
training context, native partner identity and motor repertoire are authored
priors. No shared symbol dictionary or LLM generates meanings.

A scripted scout goes to an assigned remembered site, actually sees accessible
water, physically returns and emits one native token. This is an integration
experiment, not autonomous scouting or independent intelligence. One token
identifies a learned landmark in the assigned water context; no object/location
sequence, grammar or general coordinate language is claimed. Base-world water
remains available at the hub, so the remote-water task is not evidence that
communication is necessary for survival.

An unseen report remains unverified. The recipient follows only its own
remembered coordinates, revalidates accessible stock using its own perception,
then inspects, gathers .05kg and drinks it. Goal credit requires actual inventory
gain, native ingestion and observed need relief. A separate durable confirmation
record links that report to its own three native action receipts. The immutable
original report is never relabelled as fact. Depletion by another real actor
produces no gather attempt or success claim.

The need scheduler is evaluated separately from the assigned scout task. It
uses current native hunger/thirst and learned own gather/consume relief, with
an authored .45 need threshold and count-based predictions. It receives no
assigned target/goal. Across five six-decision windows it chooses and completes
nine drink goals, revisits personally observed sources once per seed, and records
21 bounded inspection/inquiry affordances. Frozen predictions produce no need
goals and 30 inspections/inquiries from the same starting needs. A separate
native regression verifies a need-selected action can use a real location report
when own accessible/source memories do not resolve it. Suitable carried supplies
are consumed first to avoid gathering twice after an interrupted primitive.

Inquiry flags and inspection/rest are authored affordances; they are not learned
request signals transmitted to a scout. Routing, action prerequisites, memory
limits and the one-site attempt cap are also authored. The trained relief and
vocabulary tables remain frozen during scoring; this is retention and prediction
dependence, not a cure for the existing H1 online-adaptation counterexample.

## Costs, continuity and scarcity

The primary receiver travels a mean 10m per trial in every arm. It uses a mean
7 native requests with enabled signals, 5.5 muted/identity-only and 4 scrambled;
successful acquisition adds inspection/gather/drink, so fewer requests in failed
arms do not mean a better policy. Full scout travel and action records are retained.
Enabled trials use no curiosity or protective fallback. Muted and identity arms
each use ten explicitly counted private curiosity tie breaks. Wrong-location
failed attempts are missed feasible remote opportunities under the one-site
budget; depleted-source cases are legitimate scarcity and are scored separately.
No native request in confirmation is rejected or fails. Model calls are zero
from actual saved database queries, not inferred from missing files.

The study takes **392.092 wall seconds**, overlapping full regression work on
this host. Each arm resumes in a new process from a matched native head. Body
needs, stock, native scheduler, private RNG, memories and evidence persist.
Counterfactual branches are not concatenated into one life. Two-decision then
six-decision need milestones occur within the same save, without resets.

All four human bodies are alive at health 1.0 at every measured branch endpoint;
the longest endpoint is 303 simulated seconds. There are no animals in H4 worlds.
This short result does not establish unattended survival or improve G husbandry.
The need comparisons use equal decision counts, not equal final simulated time;
they are prediction ablations, not a long-term survival comparison.

## Verification and retained failures

**304 Python tests and four native checks pass.** The Python suite takes
447.369 seconds internally / 448.597 subprocess seconds. Sixteen focused H4
checks cover real report use, false-input/source refusal, native consumption,
carried inventory, atomic/idempotent updates, save/resume and archive snapshots.
Static inventory parses 121 Python files with no broken local connections or
repeated substantial production functions; pyflakes passes. The independent H4
auditor recomputes native effects and costs against actual saved worlds. Phase9's
independent audit verifies all 3439 files and retains `advance: false`.

The first development run fails: it submits eating with a one-second duration,
and the unchanged native validator returns `INVALID_ARGUMENT` (minimum two
seconds). The controller duration is fixed; the failed world, native receipts,
log and exact source ZIP are retained. Early repeated-update unit checks also
expose tuple/list return-value differences across persistence; the return boundary
is normalized without changing native physics. Development 2/3/4 and their raw
outcomes remain separate evidence; improvements are not pooled as held-out trials.

Exactly-once protection applies to native primitives and atomic learning/report
updates. An entire interrupted scout circuit is not one atomic resumable goal.
Long-term stale-report trust, repeated depleted-memory revisits and multiwriter
coordination remain limitations; the source/evidence quotas stop explicitly.
The existing H1 online-adaptation and G animal-care failures remain failures.
