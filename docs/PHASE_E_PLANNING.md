## Contracts

One existing stabilization writer handles all requests, including operator
assigned hierarchical tasks. Support obtain_food, obtain_wood, craft_tool,
make_planks, build_trough, provide_water, tend_animal, inspect_problem and rest.
General pen topology and teaching procedures remain explicit unsupported tasks
until their physical/knowledge contracts exist; do not count them as success.
Task decomposition is authored procedural knowledge supplied explicitly with
the assignment, recorded per recipient; the native recipe registry is never an
agent knowledge source. No initial knowledge profiles or teaching claim (F).

Planning uses own inventory/tools, local permitted sight and own receipt-linked
experience. Revalidate every primitive. Gather finite stock, harvest real trees,
craft an actual axe, repair broken-tool prerequisites by crafting another from
available constituents, build an actual trough and deliver real carried water.
Unknown resources/peers cannot be looked up through operator snapshots. Bounded
local search/route attempts may fail honestly. Urgent human needs preempt tasks
between native actions; live actions cannot be replaced by fabricated completion.

Task retries, steps, search, deadlines, records and model calls are bounded.
Persist task stage, pending requests, experience, hypotheses and reusable
procedure evidence separately from episodic memory and native workmanship.
Promotion requires actual own completed receipts and achieved observable goal
predicates; merely parsed plans or accepted actions are insufficient.
Failures update a bounded, explicitly authored source-selection preference.
Memory ablations keep receipts but disable that preference. This is non-neural
experience use, not the Phase 9 learner or improvement of model weights.

Optional model assistance chooses only among authored currently feasible next
operators. Reserve attempts durably before calling; cap attempts and report
timeouts, invalid replies, latency, tokens and deterministic fallback. Model-off
is default. Bounded E experiments do not clear A's recurring fair/global budget
gate or inherit Windows AppContainer claims. Unsupported model/task choices fail
closed. No unbounded live inference, new dependencies, breeding, cooking, speech
or native 3D mechanics.
