# Developmental track: prospective H0/H1 and conditional H2 protocol

21 October 2026. Separate from the sealed, failed Phase9 study. No release number
is assigned. Existing native UW9/DB10 laws and G survival policies are unchanged.
This protocol precedes new measurements. Source registration follows development
and precedes confirmation. Failed registrations/runs remain retained.

## H0 and authored priors

Explicit new, guided research worlds only. No mature inhabitant is reset or
attached as a blank learner. `developmental-1` is a mechanism/schema identifier,
not an application release. Private learner state starts with empty outcome,
object-memory, production and comprehension tables and no validated procedures.
Native sensory categories, mass/distance quantization, motor vocabulary, needs,
seeded PRNG, count update, exploration/task budget and channel constraints are
authored priors. Existing recipes and physical validators are authored laws.

No model is used. Learning is incremental counts from own observable native
feedback. Categorical sensory IDs are hashes of native perceived categories;
they are not an invented-symbol dictionary. Confidence `(successes+1)/(n+2)`
is an uncertainty heuristic, not a calibrated probability. Object memory keys
include run/person/object; reusable associations exclude object ID and position.
Policies query one person's indexed state, never another store or operator map.

Research uses dt1s, finite food/water, no regeneration, no body-law changes and
no survival claim. The curriculum supplies declared native operator-introduced
sources. Their mass is accounted as boundary input. No checkpoint editing,
teleportation, silent replenishment or time reset. Study caps precede urgent
needs; any protective support is reported rather than credited to learning.

## H1: learning source affordances

Development seed41. Confirmation seeds8101,8111,8123,8147,8161. Four arms:
learning, frozen-initial, object-memory-only and strong authored. Each starts a
new, separately named cohort world; each lifetime continues through training
and evaluation. Every arm receives the same15 native training probes (three
repeats of near food, near water, far food, insufficient food and an unavailable
target). Training probes are authored exploration, not autonomous discoveries.

One task: choose an observed source and attempt to gather0.001kg food. Store
decision observation, feature prediction, native request/terminal result, own
inventory delta and the update. A completed water gather is a completed action
but an unmet food goal. Native rejections retain their actual error categories.
Range/mass bins are coarse sensory features, not the native validator predicate.

Twelve held-out situations per arm introduce new opaque IDs and shuffle source
positions/order. They balance normal opportunities, insufficient alternatives,
far alternatives and no feasible source. Learning is frozen during scoring.
Only nine feasible opportunities form the completion denominator; inactivity
on a feasible opportunity scores zero. Scarcity abstention is reported separately.
Strong authored selection explicitly knows native food/reach/stock rules; it is
an upper comparator, not the learner's input. Object memory has no outcome for
new IDs. Frozen-initial retains the optimistic0.5 prior. Tie choices use saved
private randomness. All arms advance equal physical ticks, including abstention.

H1 promotion requires: all five complete paired cells; learned mean feasible
completion >=0.8 and >=0.2 above both frozen-initial and memory-only; >=4/5 seeds
improve over each control; at least one deterministic decision changes when
experience is removed; source isolation, exactly-once/restart/replay and balance
checks pass. No requirement to beat the strong authored controller. Report
counts, cost, need/survival diagnostics, rejection reasons and Wilson intervals.
Cap:120wall seconds/cell,1800wall seconds total, bounded2048 experiences/person.
Stop promotion on failure. No re-tuning using confirmation outcomes.

## Conditional H2: native grounded naming, then message-only reference

Proceed only after H1 passes. Same development/confirmation seeds; register the
H2 implementation separately before confirmation. Two private learners, both
initially empty. A16-symbol alphabet and one-token messages are authored limits.
The speaker coins unused opaque symbols using its own saved PRNG; no meanings
are supplied. Listener counts are partner-specific and updated independently.

Reuse native `speak` delivery/time/hearing/occlusion. Native text carries only
one opaque token, with no English translation or target ID. Old text speech is
unchanged. No LLM. No new global lexicon or synchronization of private mappings.

Authored grounding support is a real physical demonstration: the speaker
deposits0.001kg into one of three jointly visible sources, then speaks. The
listener compares its own native before/after visible masses to identify the
demonstrated referent. This observable change, not a copied speaker target, is
the teaching cue. Speaker supplies are acquired through real gathers. Training
uses36 balanced demonstrations of three sensory-distinct source classes
(small food, larger food, small water). This is scaffolded naming, not evidence
that the sound alone carried meaning during training. No public success bit or
hidden target is provided to a learner.

Freeze both vocabularies for scored reference. The speaker receives an explicit
private target assignment. Listener receives only actually heard token plus its
own shuffled visible alternatives and chooses a native `inspect` action. Score
the actual terminal inspection target. No deposit, gesture, target metadata or
motion cue occurs during evaluation. Equal timing and balanced targets.

Twelve trials/arm/seed: learned, silence, balanced shuffled messages, frozen
random association and declared designed-code oracle upper comparator. The
oracle uses operator labels solely in its own explicitly privileged comparator;
it is never inserted into learner state. Use explicit counterfactual saved
branches from the trained life, with matching initial physical/learner states;
never describe branches as additional independent lifetimes. New randomized
source IDs/layouts control object memorization. Token swaps are a causal check.

Gate: five seeds, learned mean>=0.75 and >=0.2 above silence and shuffled, with
>=4/5 seeds improving; restart retains vocabulary and selections; counterfactual
tokens change interpretation; recipient actions and native delivery receipts
verify every claimed success. Cap240wall seconds/seed,1800wall seconds total.
Report failure without supplying a dictionary or changing thresholds.

H3-H5 remain deferred. A successful narrow naming protocol is not human language,
grammar, spontaneous intention formation, general intelligence or consciousness.
