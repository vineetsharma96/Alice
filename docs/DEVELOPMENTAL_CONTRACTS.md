# Developmental contracts

All records include mechanism ID, run/person identity, source references and
checksums. Default G source modules/native build are not edited. New opt-in
SQLite extension tables have their own checksums, source pins and bounded quotas;
DB10/native checkpoint9 format remains the existing authority. A missing chain
stops learning or yields explicit uncertainty; it never creates a remembered fact.

| Contract | Required content and authority |
|---|---|
| Experience | Own decision-time observation, request, prediction, terminal native receipt, native event copies/references, own post-observation, food delta, distinct error/category, update flag/version |
| Prediction | Own sensory feature key, counts, heuristic mean, source experience references, object-specific versus reusable origin |
| LearnedAssociation | Own feature or partner/token/percept key, observation/success counts, bounded evidence IDs, update version |
| SignalMessage | Opaque token, actual native speaker/recipient/run, delivery tick and event reference; no hidden target/gloss |
| PublicFeedback | Authored training mode, own before/after visible mass changes plus actual heard token; no operator success label |
| DevelopmentState | Explicit prior manifest, empty initial tables, person/run, durable PRNG state, counts, private vocabulary, pending reconciliation and source identity |

Native submission and learning have separate durable commits. A pending intent
is saved before execution. Resume first checks its exact request in the native
decision journal/own native receipt, never resubmitting a physically committed
request at a new observation version. One atomic private transaction publishes
the experience, learner update and terminal intent state. Duplicate reconciliation
is a no-op. Mismatch, missing receipt or missing archive is explicit failure.

Experiences store complete own observations and copied native proof, not only a
latest64 episode lookup. Policy retrieval is indexed per person; finite quotas
stop growth. Save/backup copies all extension tables. Evidence does not silently
vanish during native archive rotation; references must resolve to live or verified
archived native journals. This bounded research track is not an indefinite
history guarantee. Existing runtime/archive APIs do not authorize forgetting
developmental evidence to continue training.

Private state is process/API isolation, not encryption against an operator with
database access. Operator audit labels never enter policy functions. Supervised
external teaching is reported separately from learned associations. Primary mode
has zero LLM calls and no import of the Phase9 research learner.
