## Mechanism and provenance

Add a bounded private index of at most32 references into the existing atomic
cognitive journal. No duplicate narrative or authoritative event replacement.
Each encoded entry stores its own context, simulated onset/end, observed outcome,
appraisal salience, duration and observation/receipt references. Salience is
clamp(.2+.4*harm+.2*relief+.2*surprise). Values are authored rules; experience
supplies the records. No labels, shared memories, LLM or neural training.
Only positive elapsed own-observation intervals encode; repeated IDs do not.
Divide32 slots equally among currently represented context classes (at most8),
rounding the per-class quota down. Half each quota retains most salient links;
the other half retains most recent links, filling overlaps with recent links.
Deterministic event-ID ties; global cap32. This prevents unrelated recent
events from erasing every relevant safe observation while retaining salient harm.
Eviction removes an index link; the authoritative journal is unchanged.

Retrieval matches the exact existing eight-class perceived weather/shelter cue.
Unrelated contexts have zero decision weight. Weight=salience*exp(-age/180s)*
min(duration/10s,1). Retrieve weighted outcome, confidence1-exp(-sum(weights))
and its unmodified evidence links. Confidence is a support heuristic, not a
calibrated probability. Safe and distress evidence compete in the same weighted
estimate. Nothing infers another person's intention or private state.

Connected memory replaces only the F4 learned-cue prediction supplied to the
existing bounded safety alternative. Native weather/survival urgency, own-visible
roof, routes, cooldown and validation remain unchanged. Empty retrieval has zero
confidence rather than inventing an experience. Disconnected memory encodes but
retains the unchanged F4 decision rule; frozen memory does not encode and starts
empty on new enrollment. All modes retain the F4 affect/learning pipeline.
