# H3 native verification protocol, registered before new measurements

The incoming d54a007 H3 report is a dictionary-only algorithm demonstration.
It does not execute native speech, deposits, movement, inspections, persistence,
or hearing isolation. Its original files/results remain in Git and in
`artifacts/incoming_d54a007_sources.zip`. They do not satisfy H3. This protocol
supersedes that experiment for promotion; it does not rewrite its results.

Prerequisites: original repaired H1 and native H2 source registrations and gates.
Development seed 41. Confirmation seeds 8101, 8111, 8123, 8147, 8161 are reused
explicitly from earlier milestones in new cohorts, not advertised as never-seen
seeds. Freeze new sources before confirmation; do not tune on confirmation.

Use a new 32 by 32 metre world, four native bodies, finite existing authored
food/water, no regeneration, no model calls, and no animals. Animal expansion is
outside this experiment. H1/H2 and G defaults, native physics and sealed studies
remain unchanged. Route people using only their own observations through native
movement; never teleport or rewrite a snapshot. Routes have 96-step limits.

Agent 1 teaches agent 2 three H2 sensory classes through 12 actual, balanced
deposit-and-speak demonstrations. Agents 3 and 4 remain at a distant station;
capture their actual native observations after every demonstration and require
zero audible reports from agent 1. Agent 4 privately coins its own three tokens
by viewing separate objects. Compare production conventions without copying any
mapping into another person's private state. Distinct conventions may arise by
chance; equality is a reported result, not a forced failure or a redraw.

Agent 3 must have empty task/symbol associations, then receives a single declared
activation record. Recruitment preserves every other person's full state.
Move people through actual actions; no resets of needs, supplies or history.
Save one training life, then make five explicitly counterfactual SQLite backups.
Evaluate each complete arm in a new process. Never sum branch lifetimes into
a continuous lifespan. Each trial scores a completed native inspect receipt.

Five arms, 12 balanced trials each:

1. Untrained newcomer: agent 3 hears agent 1, without demonstrations.
2. Trained newcomer: 18 balanced native demonstrations, then frozen reference.
3. Retention: agent 2 receives twelve different native, single-exposure food/water
   size pairings, then frozen reference to the original classes.
4. Unrepaired ambiguity: agent 2 hears unfamiliar agent 4 conventions and guesses.
5. Authored repair: the same unfamiliar convention triggers a count-tie detector.
   If tied/unknown, perform one real physical demonstration, then score against
   fresh untouched objects after another message. The repair controller receives
   the assigned target; the listener interpreter never does. Record each repair.

Only repair-arm learning is enabled during scoring. This tests unfamiliar-signal
repair, not homonym resolution, learned request grammar, or autonomous teaching.
Private count tables keep at most six total active associations/person; counts
of three or more are protected. Excess weak entries are archived with native
evidence, at most 64 archived slots/person; protected or archive overflow stops
explicitly. Twelve distractors plus three protected core associations should
leave three active distractors and nine archived ones. Failed/quota events are
reported, never bypassed. Passive restart persistence is separate from this
authored interference protection rule. Each learner still has 2048-record quota.

Gate, unchanged from the substantive incoming thresholds:

- Newcomer mean >= .75, >= .20 above untrained, >= four/five seeds improve.
- Retention mean >= .75, exactly three original protected classes retained and
  all nine evicted native distractors traceable.
- Repair improves >= .20 above unrepaired; no hidden target reaches interpreter.
- All trials have native speech/inspect receipts, native invariant and replay
  checks, zero model calls, matched initial branch heads, original other-person
  vocabularies preserved, no initial distant exposure, fresh-process resume.

Report rates/counts, descriptive Wilson intervals, repair count, rejection reasons,
each branch simulated duration and study wall seconds. Caps: 240 wall seconds/arm,
600/seed and 3000/study, plus 300-second child-process limit. A cap or physical
failure stops the study with its logs retained. Never substitute generated JSON
or an in-memory selection for a completed world action. No survival superiority,
independent goals, language emergence, release label, H4 or H5 claim.
