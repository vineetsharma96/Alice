# H5: bounded sequence reuse and operator learning evidence

The prospectively frozen H5 reuse gate passes on five held-out native cohorts.
An operator-only read-only panel displays actual observations, private associations,
source IDs, exposure counts, original signals and recipient decisions. This is a
narrow reference experiment with an **authored factor encoder and learning rule**.
It does not establish invented syntax, general language or autonomous conversation.
The G executable/version and all previous registered experiments remain unchanged.

## What was implemented

`underworld/composition.py` extends only newly initialized opt-in research saves.
Each speaker privately coins random IDs for its own observed native category and
coarse mass factors. Those two sensory axes and one-symbol-per-factor production
are authored inductive biases. Meanings are not embedded in channel IDs and a
partner's dictionary is never copied. Message order is privately randomized;
there is no supplied noun/adjective order. H5 uses a separate interpretation
context; the unchanged H2/H4 single-symbol mechanisms do not become sequence
parsers or live autonomous policies.

The recipient learns only from its own before/after observations of exactly one
native .001kg deposit, plus actual native speech. Each token's possible features
are intersected across lessons. Exposure counts, conflicting/ambiguous hypotheses
and private source IDs persist. The authored overlap scorer interprets messages
using these learned hypotheses. Whole-message lookup is a separate frozen control.
An intended target is supplied to the sender/scoring instrument, never to the
recipient selection function. A selection alone earns no goal credit.

Finite limits are contractual: at most2 distinct channel IDs, one native simulated
second per token,16 production factors,64 partner-token hypotheses,64 whole-message
pairs and16 references per association. Existing2048-record/person and native
quotas remain. Space for message intent, native experience and logical receipt is
reserved before physical execution; exhaustion stops explicitly. Source references
are checked before a learner uses an association, as well as by the full audit.
The native validator and physical laws are unchanged.

Logical message IDs bind to one durable native request. Repeated messages with
the same identity/text and repeated learning updates are idempotent. Conflicting
identities and unsubmitted intents at changed heads are refused. Existing native
reservation/receipt recovery and checkpoint/epoch protection remain in force.
The entire authored lesson circuit is not an atomic transaction.

## Computation, needs and continuity

Study wall time **342.163507 seconds**, overlapping the broad regression suite.
Each arm adds12 native requests per seed: six speech/rest and six inspections.
That is60 new requests/arm, **300 total**, excluding duplicated training histories.
All complete; zero native rejections and zero model calls, confirmed from the
actual databases. The learned arm has zero random tie breaks. Whole/muted each
have 30, first-symbol 15 and second-symbol 15. Protective fallbacks are zero;
chance interpretation is explicitly counted rather than credited to learning.

Each learned/whole arm advances18 simulated seconds; muted/one-symbol arms12.
Mean wall seconds/arm, including audit/replay: learned7.315, whole8.526,
muted9.033, first8.708, second8.196. These overlapping timings are implementation
cost measurements, not intrinsic intelligence speed comparisons. The longer
two-symbol channel has an explicit additional physical-time cost.

Training and each scored branch retain native bodies, resources, scheduler and
private memories continuously. Six accounted operator inputs total1.26kg of
resource per training world; teaching deposits consume genuinely gathered carried
supplies. No silent replenishment or body resets. Branches are explicit backups
of trained lives, not episodes merged into one lifetime. All four people are
alive with health 1 at all25 scored endpoints; the longest life here is93 simulated
seconds. This brief assigned reference task provides no unattended-survival result.

Fault checks cover logical intent/native reservation/native commit/private commit,
exactly-once updates, changed-head refusal, privacy, parser limits, source loss,
save equality, archive preservation and missing-archive refusal. Two supplemental
epoch tests also retain pending attention and pending message intent across an
archive; learning in a fresh process and retrying sends cause no duplicate update
or utterance. These tests were added after confirmation freeze without modifying
registered scoring/mechanism files; their source hash is recorded separately.

## Operator panel and runnable entry points

The read-only loopback `underworld.learning_panel` server reads actual native
observations and each person's retained private evidence. It shows current body
needs, completed action results, source-linked associations, original utterances,
recipient responses and separate teaching/association/authored-decision/random-
tie/protective-fallback counters. Glosses are explicitly uncertain feature
hypotheses, not guaranteed human translations. Counts are exposure, not calibrated
probabilities. Raw observations/evidence remain available in expandable details.
No panel projection is supplied to a learner or model.

Real headless Edge checks pass at 1440x900 and 390x844: selection, refresh, source IDs,
actual signals, uncertainty labels, no horizontal overflow, POST refusal, safe
hostile-text rendering and clearing stale output when evidence is unavailable.
Desktop/mobile screenshots were inspected. The existing viewer is unchanged;
this is a separate opt-in operator panel, not a repackaged application release.
Read [operations and recovery](DEVELOPMENTAL_H5_OPERATIONS.md) for commands.

## Failures retained and limits

Initial unit attempts expose a study import-path error, an authored route into
the recipient's occupied hub, and repeated checkpoint names in shared test
fixtures. Namespaced imports, a separate speaker hub and unique checkpoint names
correct those issues. Original attempt logs remain in `artifacts/h5_unit_attempt*`.
Temporary failed unit worlds were not retained. Both measured development traces
and their exact source snapshots are preserved separately; they are not substituted
for confirmation. The earlier oversized first panel observation dump is retained
in its browser evidence; the final panel folds full observations behind details.

Still unestablished: self-selected speaking, spontaneous teaching/repair,
location sequences, temporal grammar, arbitrary unseen features, conversation,
calibrated semantic confidence, unscaffolded syntax discovery and longer autonomous
survival. The factorization, coining affordance, physical attention curriculum,
overlap scorer and motor execution are authored. We measured changed recipient
behavior from learning, not invention of the learner architecture. Earlier H1
online and G husbandry failures and the original rejected H3 experiment stay
failed. Phase9's3439-file audit still returns `advance:false`; its learner remains
outside live policies. No neural training, reproduction, new speech engine or true3D.
