# H2 registration details, before implementation confirmation

Conditional on the repaired H1 gate. No outcomes have been measured for H2 when
this document is written. Development41; held-out8101,8111,8123,8147,8161.
All thresholds/budgets inherit DEVELOPMENTAL_PROTOCOL.md.

The direct user request forbids inserting a shared dictionary. Accordingly the
upper comparator is a **privileged target oracle**, not a shared designed-code
dictionary. Its correct target comes only from operator scoring labels and is
never a learner input. It is not evidence of communication. This clarifies the
earlier prospective phrase "designed-code oracle" before H2 measurement.

The authored alphabet is16 strings `s00` to `s0f`. These names encode only symbol
IDs. No global token-to-referent mapping is defined. Each speaker coins unused
symbols using its own saved PRNG and current sensory feature. Production and
partner-specific comprehension live in that individual's separate private row.
Coining is an engineered naming affordance, not learned grammar.

Sensory categories are native perceived kind hashes and coarse0.1kg mass bins.
The three tray classes are small food(~0.05kg), larger food(~0.25kg) and small
water(~0.05kg). These are authored sensory discriminations, not invented sound
meanings. A one-object-per-class task avoids within-class referential ambiguity;
no general object-identity or location-language claim follows.

The speaker obtains food/water through native gathers. Thirty-six balanced,
shuffled training trials each perform an actual0.001kg deposit into a visible
tray source, followed by one native1s speech action. The listener's private
attention record stores its own native pre-observation. Only exactly one
observed mass increase plus an actually delivered new token permits an update.
No native event/target from the speaker's private action store is queried by
the listener. This physical demonstration is explicit teaching scaffolding.
There is no public correctness bit and no hidden-target lookup in learning.

After training, make five explicit counterfactual SQLite branches from the same
life. Keep native needs, stock, private state and random state at the common
checkpoint. Every branch gets12 new-ID trials with balanced targets and shuffled
positions/order. Both vocabularies are frozen. The learned arm's entire scored
evaluation runs in a fresh process, rather than merely checking saved JSON.

Arms: learned messages, silence, balanced shuffled messages, fixed private random
token interpretation and privileged target oracle. Silence replaces speech by
an equal-duration rest. Shuffling emits the token for an independently permuted
balanced target sequence through the native channel; it does not edit a heard
packet after delivery. Random interpretation is a private seeded hash-to-sensory
rank control and has no trained associations. Oracle labels never enter other
arms or learner state. Native speech and listener inspection each cost1s.

Learner response selection receives its own current native observation, tray
candidate IDs and new actually heard token only. It receives no intended target,
trial class, operator gloss or speaker vocabulary. It selects a native inspect
request; correctness requires that request to complete on the actual intended
source. Inspection is a bounded referential action, not resource acquisition.
No training deposit, movement, gesture or correctness feedback occurs in scored
trials. Timing and scene generation are matched across arms.

Matched learned/shuffled branches provide token-swap counterfactuals: when the
actual delivered token changes, record whether interpretation changes on the
same tray scene. At least one such change is required. All native delivery
events and listener terminal receipts are retained with their source/timing.
Frozen vocabulary hashes must match before/after evaluation and after restart.

Gate: all five independent seeds/five arms complete; learned mean>=0.75,
>=0.2 above silence and shuffled; >=4/5 seeds improve over each; at least one
causal token-change response; vocabulary/restart/native proof/isolation gates
pass. Wilson intervals are descriptive; the five seeds, not branches/trials,
are the independent replicates. Cap240wall seconds per seed and1800total.
Publish source freeze before confirmation. Failures remain failures. No H3-H5
promotion, shared dictionary, LLM, human language or spontaneous teaching claim.
