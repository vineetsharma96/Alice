# H5 prospective protocol: bounded sequence reuse and operator evidence

Written before implementation measurements. Preserve all H0–H4 registered sources,
worlds, negative findings and Phase9's failed result. New opt-in four-person native
research worlds only. Models disabled. No new release label or autonomous policy.

Development seed 47. Confirmation seeds 10103, 10111, 10133, 10141, 10151.
Freeze this protocol, new mechanism, study and regression sources before confirmation.
Never tune on confirmation. Retain failed attempts separately.

Authored priors: two unordered perceptual factors, native resource category hash
and floor(mass_ug / 100000000). Each speaker privately coins one unused random
channel ID for each observed factor. This is an engineered factorized encoder,
not discovered syntax. Neither meanings nor a partner's lexicon are supplied to
the listener. Order is randomized privately for every message. A separate H5
channel accepts one or two distinct IDs from s00..s0f, costs one native simulated
second per token, and refuses longer or malformed messages. H2/H4 channels stay
unchanged. No location composition claim in this experiment.

Learning: authored physical joint attention, using the recipient's own before/
after observations of exactly one .001kg deposit and actual native speech.
Each token retains the intersection of perceptual features observed with it,
sample count and evidence IDs. Interpretation scores candidate feature overlap
with these private hypotheses; ambiguous hypotheses remain ambiguous. The
whole-message control instead counts complete unordered token-set/percept pairs.
No intended target, teacher vocabulary or operator scoring enters interpretation.

Train on food/mass bins 1 and 2, water/bins 2 and 3, two examples each.
Hold out food/bin3 and water/bin1, including from coining full combinations.
Use opaque randomized object IDs, all six objects visible, shuffled candidate
lists. Objects have accounted native operator inputs .11/.21/.31kg. Deposits
consume .001kg from genuinely gathered carried supplies, never reset bodies.
Each trial: actual speech/rest then recipient native inspect. Success requires
completed native inspection of the operator-only intended referent, not valid
JSON, planned/accepted requests or a model's claim. Frozen learned state during
evaluation. Two held-out targets x three repetitions x five seeds = 30/arm.

Matched arms from an exact trained-world backup: learned two-token, whole-message
lookup, muted, first-token-only, second-token-only. Single-token removal is a
channel ablation, not a semantic label; order randomization prevents fixed roles.
Gate: learned >=24/30 and >=.20 absolute advantage over every control; every
confirmation seed >=4/6. Report Wilson intervals and per-seed outcomes. Failure
does not block delivering a truthful implementation/panel. This tests narrow
object/attribute reuse under authored factorization, never language emergence.

Finite limits: 16 private production factors, 64 partner-token hypotheses,
64 whole-message pairs, 16 evidence references per association, one pending
attention and one message intent per actor; immutable records stop at existing
2048/person quota rather than silently evict protection. Panel reads at most64
recent records; full audit checks bounded retained records. No automatic archive
deletion. Native sources remain protected by existing checkpoint/epoch machinery.

Crash checks: before/after message intent, native reservation/commit, learning
commit; fresh-process continuation, exactly-once logical message and update,
conflicting ID refusal, changed-head refusal, private isolation, bounded parsing,
save/resume equality, archive preservation and missing-archive refusal.
Track native completed/rejected requests, protective/random ties, actual model
calls, source proofs, survival, simulated duration and wall-clock cost. Inspect
native invariants/replay. Budget: 300s/seed, 1800s study; stop explicitly on caps.
Scored branches are counterfactual copies of the same trained life, not pooled
lifetimes or evidence of unattended continuous survival. Training and each arm
retain continuous needs, resources, scheduler and memories. No replenishment.

Operator-only read-only loopback panel: actual observed behavior, native needs,
utterances and recipient decisions, private learned hypotheses/counts/source IDs,
vocabulary differences, uncertain inferred glosses beside actual IDs, and separate
external teaching, learned association, authored decision, random tie and protective
fallback counters. Panel output never enters observations or learner inputs.
Verify real browser rendering, selection and refresh, safe text insertion and
read-only endpoint behavior. No fake simulation or guaranteed translations.
