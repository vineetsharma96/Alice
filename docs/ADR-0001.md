# ADR 0001: C++ truth, Python cognition, CPU-first feasibility

Date: 2026-10-19. Status: selected for Phase 0; future contracts remain proposals.

The goal is a persistent world with humanlike pretrained inhabitants, consistent coarse mechanics and traceable teaching. Select C++20/CMake for authority and Python 3.11+ for orchestration. The available GCC 15.2.0 supports the requested standard; require it explicitly with no silent CMake standard decay. Reuse the existing native Windows compiler and stdlib Python environment. No dependency download is necessary.

Alternatives: Python-only is convenient but weakens the intended long-term native simulation boundary. A full game engine now adds graphics and setup without validating simulation or cognition. ALIEN is a useful independent artificial-life baseline: its official repository describes GPU particle organisms, genomes, neural control and evolution. It is not a drop-in pretrained humanlike inhabitant system. Its CUDA/HIP GPU requirements and rendering coupling are poorly matched to this host's integrated HD 520. Do not import/rewrite its engine; conceptual comparison needs no code reuse. Keep any future bottom-up ALIEN experiments separate from evidence about our humanlike agents.

Use an explicit small collision model initially, no Box2D dependency. Use SQLite rollback transactions first; WAL is unnecessary for a single writer and modest read access. Defer pybind11 until the fixed-step core exists. MinGW and the installed MSVC-built CPython may create extension ABI/toolchain challenges: Phase 1 must test a tiny binding before committing to this compiler pairing; use a compatible native MSVC build or a documented IPC fallback if necessary. No Python-extension compatibility is claimed by a successful subprocess smoke check.

This execution host is Windows 10 Pro, i3-6006U (2 cores / 4 threads), about 3.89 GiB RAM and Intel HD 520. These are observed here, not assumed deployment-laptop specifications. Roughly 1.18 GiB memory was free at inspection; fluctuates with other applications. CPU model-off baseline first. No CUDA device was enumerated; reported integrated adapter RAM is not measured usable model VRAM. Inference, model memory, GPU acceleration and 8/16/32-agent throughput remain unmeasured. Future local model choice requires actual free memory, latency and license verification; do not automatically download weights onto this low-memory machine.

Consequences: stable testable authority, low initial dependency cost, native Windows path, and replaceable cognition. Costs include serialization/binding work, explicit crash-atomic state ownership across languages, and intentional abstraction of biology/physics. Linux and MSVC paths are documented but untested.
