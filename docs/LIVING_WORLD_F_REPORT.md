## Implemented behavior

Explicit new-world profiles supply versioned external initialization to one
chosen recipient. The metadata manifest records every person's initial assignment,
including empty assignments. Default is none. Existing initialization paths refuse
overwrite; attach/resume never reapply a profile. Profiles record knowledge;
they do not erase the existing authored survival/crafting code or pretrained facts.

Existing native books/avatar messages preserve physical acquisition, cost and
native event references. A new guided `inject_knowledge` intervention inserts one
private `operator_injection` episode with recipient, payload, tick, branch and id.
The source is visible separately from reading/hearing in both UIs and the CLI.
Injection changes no native checkpoint, inventory, materials or workmanship.
Text is unverified inert data, never an imported program or operator capability.

An explicit one-step laboratory test uses an own accessed apparatus procedure.
An authored driver supplies its dial to the unchanged native validator; it cannot
look up the hidden answer, navigate, heat, retry or read someone else's episode.
A durable intent references the lesson before submission. The actual terminal
native result and lesson link commit atomically with memory capture. An interrupted
intent is not automatically retried or credited. Successful native practice alone
can award the existing capped water-conditioning skill.

## Remaining limits

This demonstrates a fictional apparatus rule. No new animal-care signal law was
added. The experiment author deliberately supplies a rule; ordinary pretrained
knowledge is not treated as evidence of teaching origin. No model was involved.

Profiles are inert authored text, not a general semantic skill system. Private
procedure recall examines a bounded recent window and may retain conflicting
unverified claims. Practice evidence does not globally certify every report.
Full cross-person audit access belongs only to the operator.

E's autonomous `teach_procedure` and pen-planning tasks remain unsupported. The
desktop stays read-only for teaching; stabilized saves use explicit CLI intervention
between runs. Storage quotas still stop safely without compaction. G's integrated
four-person production/care demonstration, long-term horizons and E-aware archival
remain next. Existing A model-budget limitations remain open. No neural training,
reproduction, speech, true 3D or consciousness/intelligence claims are introduced.
